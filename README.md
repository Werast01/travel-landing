# Travlog - адаптивный лендинг туристического агентства

Вёрстка лендинга по макету из Figma: десктоп (1440), планшет (1024) и телефон (430).

**Демо:** https://werast01.github.io/travel-landing/

## Что сделано
- **10 блоков по макету:** шапка, hero с коллажем, партнёры, услуги, лента направлений, Travel Point, Key Features, отзывы, подписка, подвал.
- **Адаптив mobile-first:** Flexbox и CSS Grid, брейкпоинты 768px и 1280px, без горизонтальной прокрутки от 320px.
- **Коллаж hero масштабируется целиком** через container queries (`cqw`) - пропорции макета сохраняются на любой ширине.
- **Дизайн-токены** в CSS-переменных: цвета, шрифты, отступы сняты из Figma.
- **Плавная типографика** через `clamp()`: размеры заголовков меняются вместе с шириной экрана.
- **JavaScript без библиотек:**
  - мобильное меню (aria-атрибуты, закрытие по Esc и по клику на пункт);
  - лента направлений: свайп + стрелки, scroll-snap, стрелки блокируются на краях;
  - слайдер отзывов со стрелками и точками;
  - форма подписки с проверкой email и сообщением.
- **Доступность:** семантические теги, ссылка «к содержимому», `alt` у картинок, видимый фокус с клавиатуры, `prefers-reduced-motion`.
- **Скорость:** `loading="lazy"` у картинок ниже первого экрана, `width`/`height` против «прыжков» вёрстки, `font-display: swap`.

## Стек
HTML5, CSS3, JavaScript (без фреймворков и сборщиков).

## Структура
```
index.html
css/reset.css      сброс стилей браузера
css/variables.css  цвета, шрифты, размеры из макета
css/style.css      стили блоков (mobile-first, брейкпоинты 768 / 1280)
js/main.js         меню, лента, слайдер, форма
images/            картинки и иконки, экспортированные из Figma
```

## Запуск
Открыть `index.html` в браузере. Для удобной разработки - расширение Live Server в VS Code.

## Отличия от макета
- **Шрифт:** в макете Circular Std (платный) - заменён на бесплатный близкий DM Sans (Google Fonts).
- **Услуги:** в макете третья карточка уходит за край экрана - здесь все три в сетке внутри контейнера.
- **Отзывы:** в макете один отзыв - добавлены ещё два (заглушки), чтобы слайдер работал.
- **Жёлтый «билет» у блока Travel Point** показывается от 1440px: на более узких экранах ему нет места справа от текста.
